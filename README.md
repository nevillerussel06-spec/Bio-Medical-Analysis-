# 🩺 Biomedical Information System with CDSS

A Python-based **Biomedical Information System** developed using **Streamlit** for collecting, analyzing, and visualizing patient biomedical data.
The project includes a **Clinical Decision Support System (CDSS)** that identifies predefined risk indicators, generates alerts, and provides decision-support information.

## ✨ Features
* Patient information and vital-sign input
* Biomedical data analysis
* Automatic BMI calculation
* Risk-indicator detection
* Alerts and recommendations
* Interactive charts and dashboard
  
## 🛠️ Technologies
* Python
* Streamlit
* Pandas
* Plotly
  
## 📂 Project Structure
```text
Bio-Medical-Analysis/
├── app.py

└── README.md
```
## ▶️ Run the Project
Install the required libraries:
```bash
pip install streamlit pandas plotly
```
Run the application:
```bash
streamlit run app.py
```
## ⚠️ Disclaimer
This project is an **educational prototype**. The generated results are based on predefined project thresholds and should not be considered a medical diagnosis or a substitute for professional medical advice.
