# 🩺 Biomedical Information System with Clinical Decision Support System (CDSS)

A Python-based **Biomedical Information System** developed using **Streamlit** to collect, analyze, and visualize patient biomedical information. The project includes a **Clinical Decision Support System (CDSS)** that identifies predefined risk indicators, generates alerts, and provides decision-support information based on the entered patient data.

## 📌 Project Overview

This project demonstrates how biomedical data can be processed and presented through an interactive web-based application.

The system allows users to enter patient information such as:

* Patient ID
* Age
* Sex
* Blood pressure
* Heart rate
* SpO₂
* Temperature
* Respiratory rate
* Blood glucose
* Hemoglobin
* Height
* Weight

The system then analyzes the entered data and presents the results through an interactive CDSS dashboard.

## 📂 Project Structure

```text
Bio-Medical-Analysis/
│
├── app.py
├── analysis.py
├── cdss.py
└── README.md
```

### `interface.py`

The main Streamlit application. It provides the user interface for entering patient information and navigating between the patient-information and CDSS-result sections.

### `analysis.py`

Contains the data-analysis functions used to:

* Identify risk indicators
* Generate alerts
* Generate decision-support recommendations
* Analyze patient data
* Calculate statistical information

### `cdss.py`

Contains the CDSS dashboard and visualization components, including:

* Patient information summary
* Vital-sign results
* Laboratory results
* Risk indicators
* Alerts
* Decision-support information
* Blood-pressure chart
* Vital-sign visualization
* Laboratory visualization
* Temperature and respiratory-rate analysis
* Risk-indicator chart

## ▶️ How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/nevillerussel06-spec/Bio-Medical-Analysis.git
```

### 2. Navigate to the project folder

```bash
cd Bio-Medical-Analysis
```

### 3. Install the required libraries

```bash
pip install streamlit pandas plotly
```

### 4. Run the Streamlit application

```bash
streamlit run app.py
```

The application will open in your web browser.

## ⚠️ Medical Disclaimer

This project is an **educational and academic prototype** designed to demonstrate biomedical data analysis and clinical decision-support concepts.

The results generated by this system are based on predefined project thresholds and **must not be considered a medical diagnosis, treatment recommendation, or emergency medical advice**.

The system may produce inaccurate or incomplete results. Any real-world medical decision should be made by a qualified healthcare professional or relevant field expert.
